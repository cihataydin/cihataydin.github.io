Introduction to Deep Learning

October 19, 2026 · 9 min read

In this post, we will take a look at the fundamentals of deep learning.

Perceptron - Forward Propagation​

y^=g(w0+∑i=1mxiwi)\hat{y} = g\left(w_0 + \sum_{i=1}^{m} x_i w_i\right)y^​=g(w0​+i=1∑m​xi​wi​)

Here, y^\hat{y}y^​ is called the output, ggg the activation function, xix_ixi​'s the inputs, wiw_iwi​'s the weights, and w0w_0w0​ the bias. A linear combination of weights and inputs is passed through a non-linear function to produce an output. This structure is called a perceptron that performs forward propagation. If inputs and weights are written in vector/matrix form, the following equation is obtained:

y^=g(w0+xTw)\hat{y} = g(w_0 + \mathbf{x}^T \mathbf{w})y^​=g(w0​+xTw)

where x\mathbf{x}x and w\mathbf{w}w are defined as:

x=[x1x2⋮xm],w=[w1w2⋮wm]\mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_m \end{bmatrix}, \quad \mathbf{w} = \begin{bmatrix} w_1 \\ w_2 \\ \vdots \\ w_m \end{bmatrix}x=​x1​x2​⋮xm​​​,w=​w1​w2​⋮wm​​​

Activation Functions​

Real-world problems are too complex to be solved using only linear operations. Therefore, activation functions are used in neural networks to introduce and teach non-linear relationships.

Sigmoid​

Takes values in the range of 000 and 111.

g(z)=σ(z)=11+e−zg(z)=\sigma(z) = \frac{1}{1 + e^{-z}}g(z)=σ(z)=1+e−z1​

Its derivative:

g′(z)=g(z)(1−g(z))g^{'}(z)=g(z)(1-g(z))g′(z)=g(z)(1−g(z))

Usage in TensorFlow and PyTorch:

tf.math.sigmoid(z)
torch.sigmoid(z)

Hyperbolic Tangent​

Takes values in the range of −1-1−1 and 111.

g(z)=tanh⁡(z)=ez−e−zez+e−zg(z)=\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}g(z)=tanh(z)=ez+e−zez−e−z​

Its derivative:

g′(z)=1−g2(z)g^{'}(z)=1-g^{2}(z)g′(z)=1−g2(z)

Usage in TensorFlow and PyTorch:

tf.math.tanh(z)
torch.tanh(z)

Rectified Linear Unit (ReLU)​

Takes values greater than 0.

g(z)=max⁡(0,z)g(z)=\max(0,z)g(z)=max(0,z)

Its derivative:

g′(z)={1,z>00,otherwiseg^{'}(z) = \begin{cases} 1, & z > 0 \\ 0, & \text{otherwise} \end{cases}g′(z)={1,0,​z>0otherwise​

Usage in TensorFlow and PyTorch:

Building Neural Networks​

Perceptron - Multi-Output​

By using multiple perceptrons, a layer with multiple outputs can be built.

ziz_izi​ is defined below (i=1,2)(i=1,2)(i=1,2):

zi=w0,i+∑j=1mxjwj,iz_i = w_{0,i} + \sum_{j=1}^{m} x_j w_{j,i}zi​=w0,i​+j=1∑m​xj​wj,i​

Usage in TensorFlow:

Usage in PyTorch:

Dense Layer​

Layers where every input is connected to every output are called dense layers (or fully connected layers). Below is an example of a custom dense layer implementation.

Usage in TensorFlow:

class MyDenseLayer(tf.keras.layers.Layer):
    def __init__(self, input_dim, output_dim):
        super(MyDenseLayer, self).__init__()
        
        # Initialize weights and bias
        self.W = self.add_weight([input_dim, output_dim])
        self.b = self.add_weight([1, output_dim])
    
    def call(self, inputs):
        # Forward propagate the inputs
        z = tf.matmul(inputs, self.W) + self.b
        
        # Feed through a non-linear activation
        output = tf.math.sigmoid(z)
        return output

Usage in PyTorch:

class MyDenseLayer(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(MyDenseLayer, self).__init__()
        
        # Initialize weights and bias
        self.W = nn.Parameter(torch.randn(input_dim, output_dim, requires_grad=True))
        self.b = nn.Parameter(torch.randn(input_dim, output_dim, requires_grad=True))
        
    def forward(self, inputs):  
        # Forward propagate the inputs
        z = torch.matmul(inputs, self.W) + self.b
        
        # Feed through a non-linear activation
        output = torch.sigmoid(z)
        return output

Single-Layer Neural Network​

So far, we only had an input layer and an output layer. Now, let's add a hidden layer. The components of this layer also act as perceptrons.

Hidden layer outputs:

zi=w0,i1+∑j=1mxjwj,i1z_i = w_{0,i}^{1} + \sum_{j=1}^{m} x_j w_{j,i}^{1}zi​=w0,i1​+j=1∑m​xj​wj,i1​

Final outputs:

y^i=g(w0,i2+∑j=1ng(zj)wj,i2)\hat{y}_i = g\left(w_{0,i}^{2} + \sum_{j=1}^{n} g(z_j) w_{j,i}^{2}\right)y^​i​=g(w0,i2​+j=1∑n​g(zj​)wj,i2​)

Usage in TensorFlow:

import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(n),
    tf.keras.layers.Dense(2)
])

Usage in PyTorch:

from torch import nn

model = nn.Sequential(
    nn.Linear(m, n),
    nn.ReLU(),
    nn.Linear(n, 2)
)

Deep Neural Network​

Now we are at the core of the topic! We can increase the number of hidden layers as much as we want. Each layer processes the output received from the previous layer and deepens the representation by computing new input-output transformations through perceptrons.

Hidden layer outputs:

zk,i=w0,ik+∑j=1nk−1g(zk−1,j)wj,ikz_{k,i} = w_{0,i}^{k} + \sum_{j=1}^{n_{k-1}} g(z_{k-1, j}) w_{j,i}^{k}zk,i​=w0,ik​+j=1∑nk−1​​g(zk−1,j​)wj,ik​

Usage in TensorFlow:

import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(n1),
    tf.keras.layers.Dense(n2),
    #...
    tf.keras.layers.Dense(2)

Empirical Loss​

The difference between the predicted value and the actual target value is called loss.

L(f(x(i);W),y(i))\mathcal{L}(f(x^{(i)};W), y^{(i)})L(f(x(i);W),y(i))

The first component is the predicted value, and the second is the ground truth. L\mathcal{L}L is the loss function that measures the discrepancy between these two values.

Empirical Loss / Cost Function​

JJJ is referred to as the cost function. It is used to measure how accurate or inaccurate the neural network's predictions are across a dataset.

J(W)=1n∑i=1nL(f(x(i);W),y(i))J(\mathbf{W}) = \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}\left( f(x^{(i)}; \mathbf{W}), y^{(i)} \right)J(W)=n1​i=1∑n​L(f(x(i);W),y(i))

Binary Cross-Entropy Loss​

If the outputs are restricted to binary values {0,1} (i.e., for binary classification problems), the following cost function is used. For example, predicting whether a customer will buy a product or not.

J(W)=−1n∑i=1n[y(i)log⁡(f(x(i);W))+(1−y(i))log⁡(1−f(x(i);W))]J(\mathbf{W}) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y^{(i)} \log(f(x^{(i)}; \mathbf{W})) + (1 - y^{(i)}) \log(1 - f(x^{(i)}; \mathbf{W})) \right]J(W)=−n1​i=1∑n​[y(i)log(f(x(i);W))+(1−y(i))log(1−f(x(i);W))]

Usage in TensorFlow:

loss = tf.reduce_mean(tf.nn.softmax_cross_entropy_with_logits(y, predicted))

Usage in PyTorch:

loss = torch.nn.functional.cross_entropy(predicted, y)

Mean Squared Error (MSE)​

To compute the cost in a neural network whose outputs are real numbers (regression problems), the following function is used:

J(W)=1n∑i=1n(y(i)−f(x(i);W))2J(\mathbf{W}) = \frac{1}{n} \sum_{i=1}^{n} \left( y^{(i)} - f(x^{(i)}; \mathbf{W}) \right)^2J(W)=n1​i=1∑n​(y(i)−f(x(i);W))2

Usage in TensorFlow:

loss = tf.reduce_mean(tf.square(tf.subtract(y, predicted)))
loss = tf.keras.losses.MSE(y, predicted)

Usage in PyTorch:

loss = torch.nn.functional.mse_loss(predicted, y)

Training Neural Networks​

The primary goal is to reduce the loss to the lowest possible level. To achieve this, we continuously update the parameters in the neural network—that is, the weights. Our goal is to find the optimal weight values that minimize the loss function.

W∗=arg⁡min⁡W1n∑i=1nL(f(x(i);W),y(i))\boldsymbol{W}^* = \arg\min_{\boldsymbol{W}} \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}\left(f(x^{(i)}; \boldsymbol{W}), y^{(i)}\right)W∗=argWmin​n1​i=1∑n​L(f(x(i);W),y(i)) W∗=arg⁡min⁡WJ(W)\boldsymbol{W}^* = \arg\min_{\boldsymbol{W}} J(\boldsymbol{W})W∗=argWmin​J(W)

Here, W={W0,W1,...}\boldsymbol{W} = \{\boldsymbol{W}^0, \boldsymbol{W}^1, ...\}W={W0,W1,...} represents the weight matrices.

Gradient Descent​

Updating the weights is performed using the gradient descent algorithm.

Algorithm:

  • Initialize weights randomly ~ N(0,σ2)\mathcal{N}(0, \sigma^2)N(0,σ2)
  • Loop until convergence:
    • Compute the gradient, ∂J(W)∂W\frac{\partial J(\boldsymbol{W})}{\partial \boldsymbol{W}}∂W∂J(W)​
    • Update weights, W←W−η∂J(W)∂W\boldsymbol{W} \leftarrow \boldsymbol{W} - \eta \frac{\partial J(\mathbf{W})}{\partial \mathbf{W}}W←W−η∂W∂J(W)​
  • Return optimal weights.

Here, η\etaη represents the learning rate.

Usage in TensorFlow:

import tensorflow as tf

weights = tf.Variable([tf.random.normal()])

while True: # loop forever
    with tf.GradientTape() as g:
        loss = compute_loss(weights)
        gradient = g.gradient(loss, weights)
    
    weights = weights - lr * gradient

Usage in PyTorch:

import torch

weights = torch.randn(1, requires_grad=True)

while True:
    loss = compute_loss(weights)

    loss.backward()

    with torch.no_grad():
        weights -= lr * weights.grad
        weights.grad.zero_()

Computing Gradients - Backpropagation​

Let's examine the impact of a small change in weights on J(W)J(\boldsymbol{W})J(W).

∂J(W)∂w2=∂J(W)∂y^∗∂y^∂w2\frac{\partial J(\mathbf{W})}{\partial w_2} = \frac{\partial J(\mathbf{W})}{\partial \hat{y}} * \frac{\partial \hat{y}}{\partial w_2}∂w2​∂J(W)​=∂y^​∂J(W)​∗∂w2​∂y^​​

Here, we defined the effect of the weight w2w_2w2​ on J(W)J(\mathbf{W})J(W) using the chain rule.

∂J(W)∂w1=∂J(W)∂y^∗∂y^∂w1\frac{\partial J(\mathbf{W})}{\partial w_1} = \frac{\partial J(\mathbf{W})}{\partial \hat{y}} * \frac{\partial \hat{y}}{\partial w_1}∂w1​∂J(W)​=∂y^​∂J(W)​∗∂w1​∂y^​​

Since the function y^\hat{y}y^​ indirectly depends on the weight w1w_1w1​ through z1z_1z1​, applying the chain rule again yields:

∂J(W)∂w1=∂J(W)∂y^∗∂y^∂z1∗∂z1∂w1\frac{\partial J(\mathbf{W})}{\partial w_1} = \frac{\partial J(\mathbf{W})}{\partial \hat{y}} * \frac{\partial \hat{y}}{\partial z_1} * \frac{\partial z_1}{\partial w_1}∂w1​∂J(W)​=∂y^​∂J(W)​∗∂z1​∂y^​​∗∂w1​∂z1​​

This determines the impact of w1w_1w1​ on the cost function J(W)J(\mathbf{W})J(W). To minimize the cost function, we can compute the partial derivatives with respect to all weights and update them accordingly.

Cost Function Optimization​

In the weight update step:

W←W−η∂J(W)∂W\boldsymbol{W} \leftarrow \boldsymbol{W} - \eta \frac{\partial J(\mathbf{W})}{\partial \mathbf{W}}W←W−η∂W∂J(W)​

If η\etaη takes a value smaller than necessary, the cost function converges slowly and might get stuck in a local minimum. If it takes a value larger than necessary, the cost function diverges. With an optimal value, it converges smoothly. For these reasons, the learning rate should be designed as a dynamic and adaptive parameter. Consequently, η\etaη should be computed based on parameters such as gradient magnitude, learning speed, and weight scale.

Mini-Batch​

In large datasets, computing the derivative ∂J(W)∂W\frac{\partial J(\mathbf{W})}{\partial \mathbf{W}}∂W∂J(W)​ over the entire dataset is computationally expensive and sometimes impossible. To overcome this, the dataset is split into small mini-batches. The derivative of the cost function is computed for these mini-batches instead of the full dataset at each iteration, and model weights are updated accordingly.

∂J(W)∂W=1B∑k=1B∂Jk(I)∂W\frac{\partial J(\mathbf{W})}{\partial \mathbf{W}} = \frac{1}{B} \sum_{k=1}^{B} \frac{\partial J_k(\mathbf{I})}{\partial \mathbf{W}}∂W∂J(W)​=B1​k=1∑B​∂W∂Jk​(I)​

During network training, mini-batch gradient descent ensures smooth convergence and allows the use of larger learning rates. Additionally, parallel computation on mini-batches significantly accelerates training.

Overfitting​

Striking the right balance in machine learning is critical. If overfitting occurs, the model fails to generalize, becomes overly complex, and memorizes noise by using more parameters than necessary. Conversely, if underfitting occurs, the model lacks the capacity to capture patterns in the data and misses even fundamental relationships.

Regularization​

Regularization is a set of techniques applied to prevent the model from overfitting to the training data and to improve its generalization ability. Below are common regularization methods:

Dropout​

During training, certain activations are randomly set to zero to prevent them from affecting the output. This forces the network not to rely heavily on any single perceptron. For instance, half of the perceptrons in a layer can be dropped out during training.

# TensorFlow
tf.keras.layers.Dropout(p=0.5)

# PyTorch
torch.nn.Dropout(p=0.5)

Early Stopping​

To prevent the model from memorizing training data and overfitting, training is stopped early before the loss drops to zero or begins rising on validation data.
